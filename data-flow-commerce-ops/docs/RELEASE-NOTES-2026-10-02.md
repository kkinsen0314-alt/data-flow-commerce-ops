# Data Flow 2026.10.02 源码更新

本文保留 2026.10.02 的版本记录与当时目录名称。当前仓库、源码目录和发布包已统一为 Data Flow，见 [2026.10.03 命名更新](RELEASE-NOTES-2026-10-03.md)。

本版本在原有 MiniClaw 电商数据运营项目上更新，不替换仓库提交历史，不改变本地已有账户、模型配置或运行数据库。

## 新版能力

- MiniClaw 原生用户名/密码登录，保留原生工作区、智能体管理和设置。
- 统一 Data Flow 品牌、青绿色主题、单一主导航、移动侧栏、表单、列表和原生确认弹窗。
- 认证后的分析创建、任务状态、分页记录和安全经营结果展示。
- 运营人员可自由对话，并携带分析结果或当前筛选看板的服务端权威上下文继续讨论。
- 五项核心经营指标、六组图表、日期/渠道/内容/场次筛选、脱敏明细分页、PNG 和 CSV 导出。
- 第 13 期五份合成 CSV 共 89 行：短视频 18、直播参与 24、渠道线索 18、销售跟进 17、订单 12。
- 七类接入方式及其准备要求；已可用的业务数据源仍是本地合成 CSV，MySQL、飞书等尚未实际连接。

看板和导出使用确定性计算；创建分析和发送 AI 消息使用已配置模型，需要逐次确认费用。结果查看、页面刷新和失败恢复不自动重发模型任务。

## 代码与运行入口

仓库继续使用 `miniclaw-commerce-ops/` 源码子目录。`native_app/` 为当前 React / TypeScript 产品界面，`scripts/build-data-flow-web.mjs` 通过构建 overlay 复用锁定的 MiniClaw 原生前端。默认登录入口为 `http://127.0.0.1:3017/login`，运营入口为 `/operations`，业务 API 监听 `127.0.0.1:3022`。

MiniClaw 依赖锁定为 `helsome/miniclaw@3ff1c8d6a0707f4a9f0957ff411758e5e141583a`，平台源码和依赖不会进入本次上传。首次安装需要独立初始化本地账号、Provider、Profile 与 Workspace；不能把源码更新视为免配置安装包或公网部署。
